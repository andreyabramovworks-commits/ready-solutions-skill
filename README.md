# Ready Solutions Skill

Локальный каталог готовых решений для разработки. Содержит 16 полных снимков исходных репозиториев без Git-истории, 2761 карточку решений с многомерными тегами, поиск и ссылки на примеры.

## Использование

Установите папку как `~/.codex/skills/ready-solutions-skill`. Правила для агента находятся в [SKILL.md](SKILL.md). Поиск: `node scripts/search.mjs "таблица" --limit 10`. Проверка: `node scripts/validate.mjs`.

### Вызов в Codex

Напишите `$ready-solutions-skill` и обычный запрос по-русски. Команды поиска знать не нужно — навык сам найдёт варианты в локальном каталоге, изучит исходники и объяснит различия.

- `$ready-solutions-skill Подбери доступную таблицу для списка сотрудников в моём React-приложении.`
- `$ready-solutions-skill Покажи несколько вариантов редактора документов и объясни, какой проще внедрить.`
- `$ready-solutions-skill Найди готовое решение для календаря, сравни варианты и скажи, что проверить перед внедрением.`

Укажите проект или стек, если он не виден из текущей папки. Навык уточнит только действительно важные ограничения. Карточки каталога помогают найти код; работоспособность и совместимость каждого варианта нужно проверять в целевом проекте.

Локальная [витрина](gallery/index.html) показывает исходники и ссылки на демонстрации. Из 2761 карточки 1272 ведут к точным примерам, 841 — к страницам компонентов, 167 — к маршрутам документации без сетевой проверки, 481 пока не имеют демонстрации. Исходные компоненты не запускаются внутри витрины. Подробности в [отчёте](reports/STATUS.md).

Материалы сторонних проектов остаются под их собственными лицензиями. Перед переносом кода проверьте лицензию конкретного источника.
